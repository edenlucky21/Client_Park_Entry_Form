Park Entry Registration System

Welcome to the park entry registration system. Submit tourist, transit, or student visitor information and access real-time admin dashboards.

📝 Submit Form (Local) 📊 View Admin Dashboard (Local)

📋 System Features:

  • ✓ Tourist, Transit, and Student form support
  • ✓ Multi-client and vehicle entry
  • ✓ Real-time admin dashboard
  • ✓ CSV export functionality
  • ✓ PDF generation for submissions
  • ✓ Search and filter records
  • ✓ Visitor statistics by type and period
Note: The form is currently accessible locally on your machine. For online access, the Flask application must be deployed to a hosting platform (Render, Railway, PythonAnywhere, etc.).

🚀 Want to Deploy Online?

  • Visit Render.com and connect your GitHub repository
  • Set Build Command: pip install -r requirements.txt
  • Set Start Command: gunicorn app:app
  • Once deployed, update the online links in this page
